# 串口调试使用指南

## 一、硬件连接

小车通过**无线串口（蓝牙/WiFi 模块）**与上位机通信，无需物理接线。初始化代码在 `main.c` 中调用 `wireless_uart_init()`。

**连接方式：**

1. 使用 PC 端的蓝牙串口助手或支持 TCP/UDP 的串口工具
2. 配对/连接到小车的无线模块
3. 打开串口监视器即可收发数据

---

## 二、命令总览

所有命令通过**无线串口发送字符串**，支持两种格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 双字符快捷命令 | `t0`, `f3` | 无需回车，收到即执行 |
| 参数命令 | `a0.5`, `n100` | 第一个字母为命令，后面跟浮点数值，以回车结束 |

---

## 三、遥测模式切换（`t` 命令）

修改 `uart_output_mode`，控制 `uart_telemetry_print()` 输出什么数据：

| 命令 | 模式 | 输出内容 |
|------|------|----------|
| **`t0`** | 电机/速度 | `flag, 电机设定速度, 编码器值, 占空比, 归一化速度, 编码器平均速度, 方向误差, 电池电压(mV)` |
| **`t1`** | ADC 采集 | `flag, ad_ave[0], ad_ave[1], ad_ave[3], ad_ave[4], 方向误差, 编码器平均速度` |
| **`t2`** | ADC + 姿态 | `flag, AD_ONE[0], AD_ONE[1], AD_ONE[3], AD_ONE[4], 方向误差, 编码器平均速度, 偏航角(yaw)` |
| **`t3`** | 姿态角 | `横滚角(roll), 俯仰角(pitch), 偏航角(yaw)` (单位：度) |
| **`t4`** | 元素检测 | `路线索引, 当前元素, 跷跷板状态, 圆柱体状态, 墙壁状态, 俯仰角` |
| **`t5`** | 圆柱体专项 | `ad_ave[0~4], 俯仰角, 圆柱体入口检测, 上表面检测, 是否退出, 风扇PWM, 圆柱体风扇PWM, 前馈PWM` |

> 发送 `t0`~`t5` 后，小车会回复 `mode,0`~`mode,5` 确认切换成功。

---

## 四、程序状态控制（`f` 命令）

直接修改 `flag` 全局变量，控制小车运行状态：

| 命令 | 含义 |
|------|------|
| `f0` | 待机/停止 |
| `f1` | 运行状态 1 |
| `f2` | 运行状态 2 |
| `f3` | 运行状态 3 |
| `f4` | 调试状态 |
| `f5` | 紧急停止 |
| `f6`~`f9` | 其他自定义状态 |

> 发送后小车回复 `flag,0`~`flag,9` 确认。

## 五、PID 参数实时调节

### 5.1 方向环参数

| 命令 | 格式 | 说明 |
|------|------|------|
| **`a`** | `a + 值` | 方向环比例系数 `kpa` |
| **`b`** | `b + 值` | 方向环微分系数 `kpb` |
| **`d`** | `d + 值` | 方向环微分系数 `kd` |
| **`D`** | `D + 值` | 角速度反馈系数 `kd_imu` |

**示例：**

```
a0.8      → 设置 kpa = 0.8
b-0.3     → 设置 kpb = -0.3
d0.05     → 设置 kd = 0.05
D1.2      → 设置 kd_imu = 1.2
```

### 5.2 速度环参数

| 命令 | 格式 | 说明 |
|------|------|------|
| **`p`** | `p + 值` | 速度环比例系数 `kp_motor`（左右电机同步修改） |
| **`i`** | `i + 值` | 速度环积分系数 `ki_motor`（左右电机同步修改） |

**示例：**

```
p2.5      → 设置 kp_motor = 2.5
i0.01     → 设置 ki_motor = 0.01
```

## 六、速度与电机控制

| 命令 | 格式 | 说明 |
|------|------|------|
| **`n`** | `n + 值` | 设置目标速度 `normal_speed` |
| **`n0`** | 特殊值 | **触发软停止**（调用 `CarControl_RequestSoftStop()`） |

**示例：**

```
n100      → 设置目标速度为 100
n50       → 设置目标速度为 50
n0        → 触发软停止
```

---

## 七、风扇/吸风控制

| 命令 | 格式 | 说明 |
|------|------|------|
| **`u`** | `u + 值` | 设置高压吸风风扇启动 PWM（范围 0~10000） |
| **`v`** | `v + 值` | 设置圆柱体吸风风扇 PWM（范围 0~10000） |

**示例：**

```
u5000     → 设置 suction_fan_pwm_start = 5000
u10000    → 设置为满功率
v3000     → 设置 suction_fan_pwm_cylinder = 3000
```

---

## 八、电磁公式系数

| 命令 | 格式 | 说明 |
|------|------|------|
| **`s`** | `s + 值` | 速度衰减系数 `s` |
| **`A`** | `A + 值` | 电磁公式系数 `A_` |
| **`B`** | `B + 值` | 电磁公式系数 `B_` |
| **`C`** | `C + 值` | 电磁公式系数 `C_` |

---

## 九、参数读取与确认

每次成功执行参数命令（`a`/`b`/`d`/`D`/`p`/`i`/`n`/`s`/`A`/`B`/`C`）后，小车会**自动回传当前全部参数值**：

```
kpa, kpb, kd, kd_imu, kp_motor, ki_motor, normal_speed, s, A_, B_, C_
```

格式为 CSV 行，方便上位机直接解析绘图。

## 十、使用场景示例

### 场景 1：调试电机转速

```
t0          ← 切换到电机遥测模式
n80         ← 设目标速度 80
p3.0        ← 加大 P
i0.02       ← 调大 I
```

观察输出：`flag, setspeed, encoder_data, duty1, normal_speed, encoder_ave, err_dir, battery`

### 场景 2：调试方向环

```
t2          ← 切换到 ADC+姿态模式
a0.6        ← 减小方向环比例
b-0.2       ← 调整方向环微分
```

### 场景 3：紧急停止

```
f5          ← 或 n0
```

### 场景 4：调试圆柱体元素

```
t5          ← 切换到圆柱体专项模式
v6000       ← 调整吸风风扇
```

## 十一、注意事项

1. **数值支持负号和小数点**：如 `a-0.5`、`p2.35`，解析函数 `uart_cmd_to_float()` 会正确处理
2. **命令区分大小写**：`d` 和 `D` 是不同的参数（`kd` vs `kd_imu`）
3. **`t`/`f` 命令的特例**：必须是双字符命令，第二个字符必须是数字（`t0`~`t5`、`f0`~`f9`），超范围会被忽略
4. **回传暂停**：执行命令后，遥测输出会暂停约 400 个 tick（`uart_feedback_hold_ticks = 400`），确保命令回显不被打断
