# 赛道透视校正与距离测量

直接用浏览器打开 `index.html`，不需要安装依赖，也不会上传图片。

使用顺序：

1. 上传赛道图片。
2. 按左上、右上、右下、左下的顺序选择同一平面上的四个角点。
3. 输入标定线 1 的真实距离，点击“选择标定线 1”，再点该线段的两个端点。
4. 输入标定线 2 的真实距离并选择其端点。两条线必须方向不同；若两条线等长，标定线 2 的距离可以留空。
5. 二维标定完成后，程序会按真实横纵比例重绘校正图；此后每点击两个点会记录一次距离。

角点可拖动微调；“撤销点”会撤销当前阶段最近的点或测量；“导出校正图”保存不带测量辅助线的 PNG。

## 精度说明

- 四个角点应位于同一个平面，并尽量对应一个真实矩形区域。
- 程序用两条不同方向的已知线段分别求解横向、纵向比例；方向越接近，计算越不稳定。
- 对等边六边形，可选择两条相邻边作为标定线 1 和标定线 2，并只输入一次真实边长。
- 四角区域不是实际矩形、标定点不准确、赛道不在同一平面或镜头畸变明显时，仍会产生测量误差。
